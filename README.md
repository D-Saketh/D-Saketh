# 📡 IoT & Research Projects


# 🌆 Smart RPL: Energy-Aware Adaptive Routing for Smart City IoT

Research project focused on improving IoT network communication by enhancing the RPL routing protocol using Machine Learning techniques.

## Objective

Develop an energy-efficient and adaptive routing mechanism for Low Power and Lossy Networks (LLNs).


## Approach

Implemented:

- Modified MRHOF parent selection
- Q-Learning based adaptive routing
- Energy-aware decision making
- Mobility-aware routing optimization


## Simulation Environment

```
Contiki OS
Cooja Simulator
Wireless Sensor Networks
```


## Evaluation Metrics

- Packet Delivery Ratio (PDR)
- End-to-End Delay
- Latency
- Energy Consumption
- Energy Efficiency
- Routing Overhead


## Mobility Models

- Random Walk Model
- Random Waypoint Model


## Research Focus

Smart Cities  
IoT Networks  
Energy Optimization  
Machine Learning based Routing
